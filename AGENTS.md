# Instructions for agents working on this repository

This repository documents the vector translation method. It holds no translation. Translation projects live in their own repositories and use the project template `templates/AGENTS.md`.

1. **Change the method from practice.** A new rule enters `method/rules.md` with the incident behind it and the project it came from. Update `method/method.md`, the affected skills and templates in the same change, so they agree.
2. **Keep it public-safe.** No working logs, correspondence, email addresses, local paths, unpublished drafts by named people, or third-party copyrighted material. Scan before every push.
3. **Tools stay standard-library Python.** Test any change to `tools/` on a copy of real translation files, never on a project's masters.
4. **Writing rules** for every file, comments included: no em or en dashes in prose; none of *legible*, *honest*, *load-bearing*, *gestures toward*, *the seam*, *quietly*, *substrate*, "the tension between", "not X but Y", "chosen, not found"; no aphoristic closers, chiasmus or "worse than" comparisons; no sentence assessing the one before; headings as plain noun phrases; British spelling.
5. **The site** is `index.html` with `assets/`, served by GitHub Pages from the repository root. Keep its stage list and rules in step with `method/`.
